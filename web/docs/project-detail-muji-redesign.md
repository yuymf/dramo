# 项目详情页（`/projects/[id]`）Muji 视觉改版方案

基于 `DRAMO - AI剧本/分镜创作工具设计规范`，对当前项目详情页及其输入/台本/角色/地点/分镜子页进行**纯视觉改版**，**保持现有布局结构不变**，仅调整色彩、字体、纹理、图标等视觉元素，目标是在保证生产力的同时营造"专注、可爱的猫咪伙伴"气质。

**核心原则：布局不变，仅改视觉**

---

## 1. 现状评估（仅视觉层面）

- **色彩与质感不统一**  
  侧栏 `ProjectSidebar` 保持 180px 宽度不变，但需调整：文字、Emoji、边框的颜色和透明度，增加留白感。顶部 Logo 使用 `/logo.jpg` 全色块，需改为线稿风格以匹配浅米色基调。
- **主内容视觉层次不统一**  
  主区域布局保持不变，仅调整背景色：从 `var(--muted-bg)` 改为纸张质感；内部模块（如 `/scripts` 的编辑器、`AI 助手` 抽屉）保持位置和尺寸，仅更换色彩为米白/燕麦色系，添加纸张纹理。`加载中...` heading 保持位置，仅更换字体为 serif。
- **按钮与输入视觉风格混杂**  
  `Button` 组件保持尺寸和位置，仅调整：从实心绿色改为描边风格，统一圆角为 4px，边线粗细为 1px，呈现"手工装订"式线条。
- **AI 助手视觉人格不明显**  
  `AIChatTriggerButton` 保持位置和尺寸，仅调整：Emoji 改为线稿 SVG，抽屉内部保持布局，仅更换背景色和遮罩层为米白色系，避免黑色半透明。

---

## 2. 风格与基调定义

### 色彩
- **背景阶梯**  
  - 页面背景：`var(--muji-cream)`（米白）+ 纸纹 `.muji-paper-bg`。  
  - 侧栏：`var(--muji-light-gray)`，以细线 `rgba(44,44,44,0.08)` 分隔。  
  - 内容卡片：`#fdfcf9` 渐变 + 轻微噪点 `.muji-paper-texture`，强调“纸页”。
- **文字/线条**  
  - 主文字：`var(--muji-charcoal)`（#2C2C2C）。  
  - 次级文字：`var(--muji-dark-gray)`。  
  - 分隔线/描边：`rgba(0,0,0,0.08)`；Hover 使用 `rgba(0,0,0,0.12)`。
- **强调色**  
  - 交互点击：低饱和鼠尾草色 `#9DA995`（可由 `--brand-500` 降饱和得到）。  
  - 状态/系统提示：使用 `#CFAF77`（猫咪暖琥珀）代替高饱和红橙。

### 字体
- **中文正文**：`"Songti SC", "STSong", "SimSun"`，配合 letter-spacing 0.02em，line-height 1.6。  
- **英文/数字**：`Georgia`, `"Times New Roman"`。  
- **UI 文本**：保留 `-apple-system` 系列，但颜色统一为炭黑/深灰，并降低字重（400-500）。  
- **标题**：使用 `.muji-serif` 类，字号 18-24px，首字母轻微字距提升，营造印刷感。

## 3. 视觉调整建议（布局保持不变）

### 3.1 顶部/侧栏（仅视觉调整）
- **Logo 区**：保持位置和尺寸，仅替换为猫咪线稿 Logo（黑色线条 + 米白背景），添加 `animate-breathe` 呼吸动画。  
- **项目搜索/按钮**：保持位置和尺寸，仅调整样式：输入框改为淡描边（1px 炭黑 8%），按钮改为"纸片"风格（透明背景 + 1px描边 + 4px圆角），Hover 填入 `var(--muji-oatmeal)`。  
- **菜单项**：保持位置和间距，仅调整：Emoji 改为统一线性图标（24px），激活态使用细长色块指示（左侧 2px 炭黑线），其余维持纯文本样式。  
- **项目名编辑**：保持输入框位置，仅添加淡淡下划线动画（0.2s scaleX），以手写编辑感受。

### 3.2 主内容区（仅视觉调整）
- **背景与板块**  
  - 保持现有容器结构和尺寸，仅更换背景为 `.muji-paper-bg` 纸张纹理。  
  - 关键模块（脚本、角色卡、地点列表）保持位置和布局，仅添加 `paper-card` 样式：阴影 `0 6px 18px rgba(0,0,0,0.06)` + 细描边。  
  - 版头保持位置，仅调整字体样式为"手账标签"：Serif 标题 + 小写英文副标题（Georgia italic）。
- **多标签导航**：保持标签位置和交互逻辑，仅调整视觉：背景改为燕麦色，标签描边，激活标签填充米白，底部 2px 纸胶色强调。  
- **空状态/Loading**：保持位置，仅调整文案字体为 serif + 添加插画（线性猫咪/纸张），淡入动画 300ms。

### 3.3 AI 助手区域（仅视觉调整）
- **触发按钮**：保持圆形按钮位置和尺寸，仅调整样式为"纸封蜡"造型：米白底、炭黑描边 + 上方猫咪线稿 SVG，呼吸动画减少 scale 幅度至 1.03。  
- **抽屉**：保持抽屉位置、尺寸和滑入逻辑，仅调整：背景改为米白渐变，右侧边缘加厚描边（2px 炭黑 8%），顶部加入"猫耳"形状或手写标题"猫咪助手"。  
- **气泡/消息**：保持气泡布局和交互，仅调整样式：使用纸张卡片 + 手写分隔线；AI avatar 使用线稿猫头 icon，系统提示用猫爪图钉。  
- **遮罩层**：保持遮罩层位置和 z-index，仅调整颜色为 `rgba(249, 247, 241, 0.8)`，并添加细噪点，避免纯黑突兀。

## 4. 视觉动效调整（交互逻辑不变）

- **Hover / Focus**：保持现有交互触发逻辑，仅调整视觉反馈：在边线和阴影上体现，避免大面积色块。推荐 `box-shadow: 0 0 0 1px rgba(44,44,44,0.2)` + `translateY(-1px)`。  
- **按钮按压**：保持点击交互逻辑，仅调整视觉反馈：短暂 scale 0.98 + 阴影减弱，模拟纸片被按下。  
- **Tab/Sidebar 激活**：保持激活逻辑不变，仅调整视觉过渡：使用 `transition: border-color 160ms ease`，配合细线显隐；禁用背景渐变。  
- **AI助手开合**：保持抽屉滑入逻辑和位置，仅调整视觉：透明度从 0.6→1；触发按钮缩放+轻晃（rotateZ ±2°）强化人格。  
- **纹理使用范围**：大背景和大卡片可使用 `.muji-paper-bg`，但输入框、按钮保持纯色，防止视觉噪点；噪点透明度控制在 0.2 以下。

## 5. 交付与后续

1. **样式落地顺序（仅视觉层）**  
   - 全局背景/色板 → 侧栏与主内容容器（保持布局） → 子页模块（脚本、角色等，保持布局） → AI 助手（保持布局）。  
2. **代码映射（仅样式调整）**  
   - 侧栏：`components/sidebar/ProjectSidebar.tsx`（仅调整按钮样式、项目名字体、导航项图标和颜色，不改变布局结构）。  
   - 主内容：各 `app/projects/[id]/@content/*/page.tsx` 与共享组件（如 `components/editor/*`）仅添加 `paper-card` 样式类、Serif 标题字体，不改变容器尺寸和位置。  
   - AI 助手：`components/projects/AIChatTriggerButton.tsx`、`AIChatDrawer.tsx`、`components/chat/AIChatPanel.tsx`（仅调整颜色、字体、图标，保持位置和尺寸）。  
   - 全局主题：`app/globals.css` 增加 Muji 变量及纹理辅助类，不修改现有布局相关样式。  
3. **验证**  
   - 使用 Next DevTools + 设计稿比对，重点检查视觉一致性，确认布局未发生变化；  
   - 确认暗色模式下不破坏纸张质感（允许淡化效果或关闭纹理）。

通过以上**纯视觉改造**，可让 `/projects/[id]` 系列页面在**保持现有布局和功能**的前提下，视觉上呈现 Muji 的留白、纸质与手账感，突出"猫咪 AI 创作伙伴"人格，同时兼顾长时间写作/策划场景的专注体验。
