# 分镜脚本合并提示词（Reduce阶段）

你已经处理了多个剧本片段，现在需要将它们合并成一个完整的分镜脚本。

{chunk_results}

## 合并任务

1. **场景重新编号**：
   - 按照时间顺序为所有场景重新编号：scene-1, scene-2, scene-3, ...
   - 更新场景标题中的序号

2. **镜头重新编号**：
   - 为所有镜头统一编号：001, 002, 003, ...
   - 镜头编号应跨越所有场景连续递增

3. **场景边界检查**：
   - 检查相邻片段的场景衔接
   - 如果两个片段的边界场景是同一个，合并这两个场景的镜头
   - 删除重复的建立镜头

4. **一致性调整**：
   - 确保相同场景在不同片段中的描述一致
   - 统一术语和表达方式
   - 保持摄影风格的连贯性

5. **质量验证**：
   - 确保每个场景都有完整的title、summary和shots
   - 确保每个镜头的所有字段都已填写
   - shot_size、camera_angle等必须使用标准中文术语

## 输出格式

严格按照以下JSON格式输出：

```json
{
  "projectId": "{project_id}",
  "scenes": [
    {
      "id": "scene-1",
      "title": "场景标题",
      "summary": "场景概述",
      "shots": [
        {
          "shot_number": "001",
          "shot_size": "远景",
          "duration_seconds": 4,
          "scene_description": "...",
          "director_notes": "...",
          "audio_description": "...",
          "camera_angle": "平视",
          "camera_movement": "固定",
          "focal_length": "35mm"
        }
      ]
    }
  ]
}
```

## 注意事项

- 不要添加markdown代码块标记
- 不要修改每个镜头的内容细节，只进行编号和结构调整
- 如果发现明显的质量问题（如空字段），标记但不要删除
- 保持原有的艺术创意和技术选择
