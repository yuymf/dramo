| 项 | 内容 |

| 产品 | Dramo |
| 对标 | [Laper](https://laper.ai)（laper.ai，赵纯想团队）当前已上线能力 |

本文回答三件事：做成什么样、先做什么、现有 Dramo 怎么收。实现细节（表字段、接口、组件拆分）在开工时另写设计，不在本 PRD 里预埋。

---

## 1. 背景与目标

Dramo 今天是「想法 → 一键生成台本 / 角色 / 地点 / 分镜」的单用户工具。Laper 是「人写语义化剧本，实体从正文推导，AI 在明确作用域里改同一份文档」的编剧工作区，并延伸到前期制作和短片制片。

**目标：在 Dramo 上完整复刻 Laper 当前已有能力。** 品牌、部署形态和图像后端用我们自己的：名称仍是 Dramo，图像生成用多路 Stable Diffusion 分担，不接 Laper 的计费与模型供应商。

做完之后，用户应能：

1. 用行业剧本格式写、改、导出一份可进组的剧本。
2. 从同一份正文得到角色、地点、道具、镜头，而不是生成后再提取一套平行数据。
3. 用有边界的 AI 改选区、场次、大纲或实体，而不是整本替换。
4. 把一场戏推进到分镜、参考图，并在 Cinema 项目里走到 15 秒成片。
5. 和同事在同一份文档上协作、评论、恢复版本。

## 2. 已锁定决策

| # | 决策 | 含义 |
|---|---|---|
| D1 | **全量复刻 Laper 当前功能** | Script 工作区、Cinema 管线、协作、公开库都在范围内。不先做「生成器加强版」。 |
| D2 | **直播 / 分支 / 提词器降为次要模式** | 不再占据默认 IA。入口收到「更多」，默认路径是场次 / 动作 / 对白。 |

## 3. 产品原则

1. **人写，AI 协助。** 默认不是代写整本。AI 必须落在选区、当前场、大纲段落、beat、实体或 Reel 阶段上。
2. **一份文档。** 键盘修改和接受的 AI 修改进入同一份剧本。不另存「AI 稿」。
3. **改源头。** 场次写错就改场次标题，不在地点卡上另造一条。
4. **视图不等于实体。** 画布 / 表格 / 关系网切换的是呈现，不是第二套数据。
5. **设计与出图分离。** 聊天可以写镜头；出图是带状态的独立任务。
6. **先跑通最小端到端，再往上加。** 第一期必须能：打开工作区 → 按节点写一场戏 → 角色和地点自动出现 → AI 只改这一场 → 导出。前三期做完之前，不启动 Cinema 成片和 CRDT。

## 4. 用户与主路径

| 角色 | 要完成的事 | 主路径 |
|---|---|---|
| 编剧 | 从一句话写到可交付剧本 | 新建 Script 项目 → 过前提/大纲/beats → 按场写作 → 诊断 → 导出 FDX/PDF |
| 导演 | 把场次变成可拍的镜头 | 选一场 → 设计决定性镜头 → 出分镜图 → 查连贯性 |
| 制片 / 选角 | 看人物、地点、道具能否进组 | 选角表、勘景表、道具连续、资产库 |
| 短片创作者 | 把一小段戏做成画面 | 新建 Cinema 项目 → 五阶段 Reel → 选成片版本 |
| 编剧室 | 多人改同一份稿 | 分享链接 + 角色权限 + 评论 + 版本快照 |

次要用户（直播编剧、互动叙事）走「更多」里的旧模式，不作为获客主路径。

## 5. 范围

### 5.1 要做（Laper 当前能力）

**Script 项目**

- 语义剧本编辑器（场次标题 / 动作 / 角色 / 对白 / 括号提示 / 转场 / 评论 / 字幕）
- 封面与正文分离
- 好莱坞格式、亚洲格式
- 页数时间轴（约 1 页 ≈ 1 分钟，只读导航）
- Outline、Beats、Episode
- 角色（画布 / 关系网 / 选角表）、地点（画布 / 关系 / 勘景表）、道具
- 世界观、知识库、顾问方法论
- 分镜（面板 / 表格 / 画布；镜头挂在推导出的场景上）
- 资产库与生成任务（肖像、地点、道具、静帧、分镜帧、海报、选角视觉）
- 有边界的 AI、分阶段冷启动、剧本医生
- FDX 导入（新建项目）、好莱坞 FDX + 亚洲 PDF/DOCX/TXT 导出

**Cinema 项目**

- 与 Script 分离的数据模型
- Reel：场景 → 表演（`@角色` `#道具` 引号对白）→ 文字分镜 → 分镜图 → 15 秒成片
- 末帧连贯 / 自然转场
- 项目级美术与画幅设定

**协作与社区**

- 账号与项目成员（OWNER / ADMIN / EDITOR / VIEWER）
- 实时协作、在线状态、离线本地层
- 锚定评论、项目级版本快照
- 公开剧本库（发布、阅读、讨论、复制到私有项目）

**平台**

- 个人设置：语言、浅色 / 深色
- 项目设置：身份、格式、AI
- 多路 Stable Diffusion 出图池

### 5.2 降为次要模式（保留入口，不占默认 IA）

| 现有能力 | 新位置 | 规则 |
|---|---|---|
| 直播 / vlog / 短视频内容类型 | 项目类型 =「口播」，或「更多 → 口播台本」 | 不出现在新建项目的默认卡片上 |
| 分支叙事画布 | 口播 / 互动项目内的一个视图 | 不进 Script 项目主导航 |
| 提词器、SRT 导出 | 口播项目的导出菜单 | Script 项目导出不展示 |
| 一键全管线（澄清→台本→提取→分镜） | 口播项目可选 | Script 默认禁止「一次生成整本」 |
| 角色三视图 | 角色维度的一个生成动作 | 保留，不当作品牌功能 |
| 灵感面板 | 并入知识库 / 资产，或口播侧栏 | 不再作为一级模块 |
| 用户自带文本 LLM Key | 设置里保留 | 出图走 SD 池，不再用「用户填的图生 API」当主路径 |

### 5.3 不做 / 不抄

- Laper 的订阅、积分、套餐页、推荐返利。
- 顾问「市场」运营。顾问先做成内置方法论镜头（三幕、Save the Cat、故事圈等），不做成可买卖角色。
- 把 Seedream / 豆包留作出图兜底。出图主路径只有 SD 池。
- 为旧 `{label,text}` 台本写双写或导入兼容。旧项目在切换日之后视为不可用，需要的话只提供「纯文本粘进新编辑器」。
- 继续维护 `/blog`、`/cases` 等已删的伪社交页。

## 6. 信息架构

对标 Laper 工作区从左到右四层。现有「左侧模块列表 + 中间内容 + 右侧固定 Chat」整页替换。

```
┌────┬──────────────┬────────────────────────────┐
│轨  │ 项目面板      │ 中央画布                     │
│    │              │  编辑器 / 画布 / 表 / 网     │
│Script│ 项目名      │                            │
│Outline│ 集数列表   │                            │
│Beats│ 维度内操作   │                            │
│Characters│        │                            │
│Locations│         │                            │
│Props│             │                            │
│Storyboard│        │                            │
│Assets│            │     ┌─────────────────┐    │
│Worldview│         │     │ AI 浮层（可拖可叠）│    │
│Knowledge│         │     └─────────────────┘    │
│Advisors│          │                            │
│(More)│            │                            │
└────┴──────────────┴────────────────────────────┘
```

### 6.1 窄导航轨

只切换维度，不放搜索、不放用户名片。

**Script 项目：** 剧本、大纲、Beats、角色、地点、道具、分镜、资产、世界观、知识、顾问。底部「更多」才出现口播台本。

**Cinema 项目：** Reels、角色、道具、任务。

### 6.2 项目面板

- 项目名、类型（Script / Cinema / 口播）
- 集数列表：新建 / 重命名 / 删除（删除前强制命名版本）
- 当前维度的视图切换：如角色的 画布 | 关系 | 选角表
- 项目操作：设置、分享、导出、版本、导入 FDX

切集只改自己的路由和文档绑定，不广播给协作者。

### 6.3 中央画布

同一实体的多种视图，切换不复制数据。

### 6.4 AI 浮层

- 浮在工作区上，可移动、可改大小、可收起。
- **不是文档的一部分**，也不再是占 28% 的永久分栏。
- Viewer 只有只读工具。
- 发送时自动带上：当前维度、当前集、光标/选区、焦点实体。

### 6.5 项目列表与新建

- `/home` 继续做操作台：最近项目、新建。
- 新建默认两张卡片：**剧本项目**、**制片项目（Cinema）**。口播是第三张弱化入口。
- 冷启动走五关，不跳进「生成完整台本」。

## 7. 设计规范（对标 Laper）

`web/DESIGN.md` 里的夜间落地页可以留。**项目工作区不再按那份备忘做。** 工作区视觉以 Laper 编辑器为准，目标是「打开就像专业剧本软件」，不是「打开像品牌站」。

### 7.1 必须对齐的结构

| Laper | Dramo 现状 | 要求 |
|---|---|---|
| 窄维度轨 | 220px 侧栏混了 Logo / 搜索 / 四模块 / 用户 | 拆成轨 + 项目面板 |
| 项目面板含集数与维度操作 | 无集数，无视图切换 | 按 6.2 做 |
| 中央按维度换编辑器/画布/表 | 四个独立 page，布局不统一 | 同一壳，只换中央 |
| AI 可拖动浮层 | `react-resizable-panels` 右侧栏 | 改为浮层 |
| 维度多视图 | 角色页左右拼列表和关系图 | 顶部 view switch，同一数据 |
| 剧本时间轴 | 幕芯片（还叫 Beats） | 只读页数轴，1 页 ≈ 1 分钟 |
| 浅色 / 深色 | 仅浅色纸 | 工作区支持 theme，跟账号走 |

### 7.2 视觉

- **工作区表面：** 接近纸白或墨黑，对比够用来长时间看稿。强调色只用于当前维度、主按钮、焦点。现有 terracotta `#c2410c` 可继续当唯一强调色，不要再叠橙渐变、纸纹、猫耳。
- **剧本正文：** 好莱坞模式用等宽（Courier Prime 一类）；亚洲模式用适合中文剧本的衬线 / 黑体，按页宽和缩进排，不能再用「卡片块 + 可编辑 label」。
- **字号与图标：** 全产品一套。Laper 0.4.1 的方向：统一字号阶梯、工具栏动作收束、图标尺寸一致。
- **动效：** 工作区禁止装饰性漂浮、噪点、无意义 hover 抬起。选中、保存、任务状态用短反馈即可。
- **落地页：** 可继续「夜间书桌 + 猫 + 开始写作」。文案改成剧本/场次/对白，不要再写直播探店。

### 7.3 设计验收（前端开工即用）

对照 Laper 工作区截图（官网编辑器、文档里的 shell 描述）逐条过：

1. 第一眼能数出四层：轨、项目面板、中央、AI 浮层。
2. 剧本页看起来像剧本，不像笔记卡片流。
3. 角色 / 地点 / 道具能在画布、表、网之间切换且实体不丢。
4. 收起 AI 后，中央画布仍是完整工作区。
5. 浅色 / 深色切换不破坏场次标题与对白层级。
6. 口播模式在「更多」里，默认新建走不到它。

实现期应对照 laper.ai 实际产品，而不是只对照本文件的 ASCII 框。

## 8. 数据模型（产品级）

现有 18 张表按直播台本设计，不能加字段凑合。切换日用新模型替换，旧表删除。

### 8.1 项目与集

- `User`：真实账号。去掉启动时写入的 `default-local-user`。
- `Project`：`type = script | cinema | spoken`。spoken 即口播次要模式。
- `ProjectMember`：角色 OWNER / ADMIN / EDITOR / VIEWER，另存展示用的工种标签（导演 / 编剧 / 制片），工种不授权限。
- `Episode`：Script 下挂剧本正文、大纲、beats、场景、镜头；Cinema 下挂 reels。
- 项目级共享：角色、地点、道具、世界观、知识、顾问、资产、任务。

### 8.2 剧本节点（Script 的核心）

正文是有序语义节点，不是 HTML 块：

`scene_heading | action | character | dialogue | parenthetical | transition | comment | subtitle`

- 场次标题解析：内外 / 地点 / 时间，写入或更新 `Scene` 与 `Location`。
- 角色 cue 连到项目 `Character`；VO / 续说是演出修饰，不新建人物。
- 封面是独立字段（标题、作者、联系方式等），不进正文。

### 8.3 规划与实体

- `Outline`：集数级 Markdown。
- `Beat`：戏剧变化单元，不是场景副本。
- `Character` / `Location` / `Prop`：项目级身份，可被正文引用，可挂参考图。
- `Worldview`：扁平 key/value。AI 默认只读，本轮消息明确要求才能写；不能删 key。
- `KnowledgeFile`：资料文件，对话里按索引检索，不整库注入。
- `Advisor`：项目当前至多雇一个内置方法论。

### 8.4 镜头、Reel、任务

- `Shot`：属于某集某场景。设计字段与生成媒体分开。
- `Reel`：Cinema 单元，五阶段状态机，成片固定 15 秒。
- `GenerationTask`：一次出图 / 出视频 / 出音频的执行记录（状态、worker、重试、失败原因）。
- `Asset`：可复用输出，可回写到角色 / 道具 / 镜头 / Reel，或留在资产库。

任务 ≠ 资产。刷新页面或估时变化不得自动再派一单。

### 8.5 协作

- 剧本与集数级结构进 CRDT 文档（对标 Loro；实现可选 Loro 或 Yjs，选一个成熟库，不自研）。
- 评论、知识、世界观、顾问、任务、资产走数据库，不进 CRDT。
- `ProjectVersion`：命名快照。恢复是整档回滚，不是挑一段。

## 9. 功能需求

下列每条都是产品验收项。未写「口播除外」的，都指 Script / Cinema 主路径。

### 9.1 语义剧本编辑器

- 段落有且仅有一种剧本角色；Tab / 快捷键切换类型。
- 场次标题、角色名自动格式化；好莱坞与亚洲两套排版由项目格式开关决定。
- 粘贴纯文本时尽量识别场次与角色；识别失败则标成动作，并提示去改类型。不把整段糊成「正文」。
- 光标和选区是 AI 的默认作用域。
- 封面与正文是两个视图。
- 时间轴随光标移动，估算页数与分钟，只读。

### 9.2 Outline 与 Beats

- 大纲是持久 Markdown，按集存储。改结构应增量改，不整篇覆盖，除非用户确认重置。
- Beat 是可排序的变化单元：动作、意图、结果。一场可以有多个 beat。
- AI 改大纲或 beats 必须先读现有结构。写完场次后，用户（或 AI 在被要求时）要能指出「哪个 beat 没在正文里兑现」。

### 9.3 实体从正文来

- 合法场次标题 → 场景 + 地点。
- 合法角色 cue → 角色。
- 改名在确认后回写全项目引用。
- 角色三视图：画布、关系网、选角表。
- 地点三视图：画布、关系 / 分组、勘景表（故事地点与实拍地分开填）。
- 道具：画布 + 列表；记录谁持有、状态、连贯要求。支持 `#道具名`。
- 禁止「先生成角色库再回头贴到剧本」作为 Script 主路径。

### 9.4 世界观、知识、顾问

- 知识库：上传 DOCX / PDF / TXT / Markdown，AI 先看目录再按需读。
- 世界观：短规则。界面可改；AI 未获本轮明确授权不得写。
- 顾问：内置若干方法论。对话可「用 XX 顾问看第 2 集大纲」，顾问不能自己雇自己，也不能改权限。

### 9.5 AI

每次请求必须能回答：改哪里、改成什么、哪些不能动、现在有没有写权限。

冷启动五关（可停、可回退）：

1. 前提：人物、欲望、阻力、代价、格式
2. 结构：大纲因果与结局承诺
3. Beat：反转与加压
4. 实体：去重、关系、地点
5. 开写：一次只写一小撮场次

另外：

- 微续写：空行停留后给出约 50–100 字建议，采纳才进文档。
- 剧本医生：按场 / 角色 / 冲突 / 主题出优先级笔记，可只诊断不改稿。
- 改世界观必须用户本轮写明要写哪几个 key。
- Viewer 不能触发写操作。

现有 `ScriptWorkflow` 一次吐 3–8 场、`DirectorWorkflow` 只回三类建议、聊天只塞页面 JSON——主路径全部替换。口播项目可继续用「生成完整口播稿」。

### 9.6 分镜与资产

- 镜头挂在由场次标题推出的场景上。剧本改了，镜头要能标过期。
- 默认引导约 3 个决定性镜头，超过 6 个时 AI 应先问是否真要加覆盖镜头。
- 视图：面板、表格、画布。
- 出图 / 出海报 / 出选角图走任务系统，回写到实体或资产库。
- Script 资产空间：任务画布 + 任务列表。

### 9.7 导入导出

| 内容 | 格式 |
|---|---|
| 好莱坞剧本 | PDF、DOCX、TXT、FDX |
| 亚洲剧本 | PDF、DOCX、TXT |
| 大纲 | PDF、DOCX、TXT |
| FDX 导入 | 仅 Script 类型，始终新建项目，不合并进现有项目 |

导出前检查标题、格式、场次标题、角色 cue。Fountain 不再作为 Script 主导出（Laper 也没有）。口播项目另提供 TXT / 提词器 / SRT。

### 9.8 Cinema

- 创建时设定画幅、制片类型、摄影与美术风格。
- 五阶段有前置：没有表演不能出文字分镜，没有镜头不能出分镜图，没有分镜图不能出成片。
- 成片 15 秒，多版本自选。
- 下一 Reel 可选上一 Reel 末帧作开场锚点。
- Cinema 助手只动 Reel / 表演 / 镜头，不改 Script 项目页面。
- Cinema 不导入 FDX。

### 9.9 协作与社区

- 每个项目固定分享链接，模式：任何人可看 / 可编 / 仅邀请。
- 评论锚定在剧本、大纲、画布实体上，与正文分存。Viewer 可评不可改稿。
- 版本：自动点 + 命名点。恢复整档，先确认。
- 公开库：只有作者主动发布才进入。公开阅读 ≠ 可编辑。允许的项目可复制到私有工作区。

### 9.10 账号与设置

- 全局：资料、语言、主题、用量（可选）、账号。
- 项目：身份、格式、AI。主题切换不翻译剧本、不改别人的界面。

## 10. 图像生成：多路 Stable Diffusion

Laper 用他们的云端出图。我们用 **多台 Stable Diffusion（或兼容 A1111 / ComfyUI 接口的实例）组成 worker 池**，由现有任务模型升级后的 `GenerationTask` 调度。

### 10.1 为什么是池，不是单端点

角色肖像、地点、道具、分镜帧、海报会并发。单实例排队会堵死工作区。多实例按负载和能力分流。

### 10.2 产品规则

- 用户在界面上只看到「任务」：排队 / 生成中 / 完成 / 失败、进度、重试。不暴露 worker 名，除非设置页排障。
- 派单前展示：对象（哪个角色 / 哪一镜）、参考图、提示词、画幅。派出去就不能因估时变化而自动再派一单。
- 结果是 Asset。不自动改剧本正文。
- 失败展示原因，纠正后再重试。

### 10.3 调度（实现约束，避免做成空配置层）

- 配置一份 worker 列表：`baseUrl`、权重、能力标签（`txt2img` / `img2img` / `controlnet` / 分辨率上限）、探活地址。
- 派单：只发给活着的、能力匹配的实例；默认选当前队列最短的。
- 某实例连续失败则摘流，探活恢复后再进池。
- 同一角色 / 同一 Reel 的连续出图尽量粘在同一 worker，便于种子和 LoRA 一致。
- 文生图、图生图、多参考融合，用 worker 能力标签路由，不在业务里写死「第 2 台专门出分镜」。

### 10.4 和现有出图的关系

- `GenerationJob` + AgentOS `ImageService` 里对 Seedream / 豆包的模式选择，在出图切换日删除。
- 用户设置里的 `IMAGE_GEN` LLM 配置不再作为主出图通道。若还要留「自定义兼容 SD 的端点」，就把它登记进 worker 列表，而不是另开一套生成器。
- 视频 / 音频（Cinema 成片、对读）不假装用 SD 做。单独选后续编码器；本期 PRD 只锁定「静帧类全部进 SD 池」。

## 11. 次要模式：口播

口播（原 live / vlog / 短视频 / 分支 / 提词器）是完整产品的附属，不是第二套主 IA。

- 新建入口弱化。从 Script 项目不能一键「转成直播稿」而不经过导出或复制。
- 口播编辑器可以继续用带标签的块、分支画布、提词器 / SRT，因为那是口播自己的语义。
- 口播可以继续走「澄清 → 生成完整稿」。
- 口播不进入公开剧本库的默认陈列（避免和行业剧本读者混在一起）。
- 不为其新做协作或 Cinema。能共用账号和项目列表即可。

## 12. 分期

按「能跑的端到端」切开。每一期结束，主路径必须可演示，而不是只交了半套表。

### 第一期 — 最小 Laper 形态（先做这个）

工作区四层壳 + 语义编辑器 + 封面 + 两种格式 + 场次/角色/地点推导 + 选区/当前场 AI 写回 + 台本级版本 + TXT/PDF/DOCX 导出 + SD 池先跑通角色肖像与地点图（至少 2 个 worker 配置位）。

**演示：** 新建剧本项目 → 手写两场 → 角色和地点自动出现 → 选中一段对白让 AI 改 → 出一张角色图 → 导出 PDF。

此期删除：默认用户中间件、一次生成整本的 Script 主路径、三 mode 假路由、右侧固定 Chat 栏。

### 第二期 — 规划与一致性

Episode、Outline、Beats、道具、世界观、知识库、顾问、角色选角表、地点勘景表、冷启动五关、剧本医生、微续写。

### 第三期 — 前期制作

镜头一等实体、分镜三视图、设计与出图分离、海报 / 选角 / 道具图进任务系统、FDX 导入导出、资产空间。

### 第四期 — Cinema

Reel 五阶段、15 秒成片、末帧连贯、Cinema 助手。视频后端另选，不进 SD 池。

### 第五期 — 协作与社区

账号与成员、分享链接、CRDT、评论、项目级快照、公开库。数据模型从第一期就按多用户建，此期打开，不在此期临时改表。

口播次要模式：第一期只做入口降级（藏进更多）；编辑器能开即可，不在第一期重写。

## 13. 验收标准

### 产品

- 对照 Laper 教程目录，Script / Cinema / 协作 / 导出导入每一节在 Dramo 都有对应入口，且行为符合第 9 节，而不是「同名页面、不同语义」。
- 默认新建路径走不到直播生成、分支画布、提词器。
- 改场次标题后，地点维度出现的是同一条地点，不是新提取的重复项。
- AI 在只给选区时，不得重写未选中的场次。
- 两台 SD worker 同时挂着时，两个出图任务能分别落到不同实例（或按最短队列分配），一台挂了另一台仍能出图。

### 设计

见 7.3。工作区不能再被认成「带聊天栏的生成器后台」。

### 技术（约束，不是方案）

- 正文以语义节点存储。Fountain / FDX / 亚洲 PDF 都从节点生成，禁止从 HTML 反推对白。
- 出图只走 worker 池。
- 无 `default-local-user`。
- 不保留旧 Script JSON 的读写路径。
